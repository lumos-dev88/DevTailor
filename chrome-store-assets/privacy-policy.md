# 隐私政策

DevTailor 是一个本地开发工具。Chrome 扩展会和你本机运行的 DevTailor Bridge 通讯。

DevTailor 不会把页面数据发送到托管的 DevTailor 服务。标记数据、聊天展示会话、截图和保存的元素目标会保存在浏览器本地存储，以及 Bridge 使用的项目 `.devtailor/` 目录中。

你选择运行的 ACP Agent 可能会收到完成任务所需的用户消息、标记元素上下文、截图和浏览器工具结果。请同时查看你所使用 Agent 的隐私行为。
