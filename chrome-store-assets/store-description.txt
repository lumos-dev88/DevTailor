DevTailor 是浏览器页面 ↔ AI Agent 前端开发桥接工具，由「Chrome 浏览器扩展 + 本地 Bridge 服务」双组件构成。

它打通真实运行页面与编码 Agent 的数据、指令链路，让 Agent 能直接获取页面 DOM、截图、元素标记、控制台信息，并在修改代码后回到浏览器执行点击、填写、断言和截图验证。

组件分工：
- Chrome 扩展：页内悬浮标记工具条（选取 / 参考元素 / 截图 / 接管状态 / 打开侧边栏）、侧边栏聊天与标记、参考元素管理、元素库、浏览器工具调用和消息流式展示
- Local Bridge：通过 SSE/HTTP 对接扩展，通过本地后端 runtime 驱动 AI Agent，并路由 Agent 的浏览器指令到已接管 tab

核心能力：
- 页面元素打点标注：VisBug 式选取（盒模型高亮）+ 就地备注，一键打包上下文发给 Agent；`Ctrl/Cmd+Shift+X` 接管或隐藏工具条
- 参考元素：点选任意元素即可把它的白名单计算样式、裁剪脱敏后的 HTML 结构和元素截图作为「参考」随消息发送（最多 8 个），不采集脚本、事件属性和表单输入值
- 截图能力：可见区域截图、图片粘贴入对话
- 元素库：项目级可复用元素目标，供 browser tool 通过 targetId / targetName 快速复用
- 浏览器工具：页面快照、控制台日志、点击、填写、按键、等待、断言、运行 JS、批量操作流程
- 任意 http/https 页面按需接管；未接管页面不注入扩展脚本
- 页内工具条可拖动并记忆位置，标记在侧边栏统一查看、编辑备注和删除
- 可在侧边栏选择在线 Claude Code 实例，或由 Hub 自动选择默认实例

适用场景：
- 本地调试前端 UI 异常，省去大段文字描述元素位置
- 让 Agent 获取真实页面 DOM、运行时错误和截图来定位代码缺陷
- Agent 修改源码后，自动在浏览器执行点击、输入、断言，即时验证效果
- 介于手动测试和重型 E2E 测试框架之间的轻量化调试自动化
